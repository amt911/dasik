# ai_skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A v3 dasik domain that declares AI skills/plugins per agent and per user, installs them through each agent's OFFICIAL CLI, plans/applies idempotently, and captures them back with `sync`.

**Architecture:** One new pydantic block (`ai_skills`), one pure state-reader module (reads the three agents' own state files under a target root, no I/O beyond `open`), and one v3 action that turns (user × agent × artefact) into domain items, converges them with the official CLIs run as the user through `su -`, and reports them back in `import_state`.

**Tech Stack:** Python ≥3.10, pydantic, `Command.execute` (`su - <user> -c … -- sh <args>`), stdlib `tomllib` with a regex fallback. External CLIs driven, never reimplemented: `claude plugin`, `codex plugin`, `npx skills`.

**Spec:** `docs/superpowers/specs/2026-09-02-ai-skills-design.md`

## Global Constraints

- No new runtime dependency. Runtime deps stay `pydantic` + `colorama`.
- Never declare a version: presence only, so `claude plugin update` / `npx skills update` stay the user's.
- Never write another tool's state file. Read defensively (missing/unreadable ⇒ "not installed"), write only through the official CLI.
- Every command runs as the target user: `Command.execute("su", ["-", user, "-c", script, "--", "sh", *args], target=…)`. Values are positional parameters, NEVER interpolated into the script string.
- `apply`/`rollback` never run for real outside a QEMU guest.
- Coverage gate 80%; mypy, bandit and the set_math mutation tier must stay green (`.githooks/pre-push`).
- Item grammar, used verbatim everywhere:
  `<user>:<agent>:marketplace:<mkt>` · `<user>:<agent>:plugin:<plugin>@<mkt>` · `<user>:<agent>:skill:<name>`
- Domain name: `ai_skills`. Agent ids are the `skills` CLI's: `claude-code`, `codex`, `opencode`, `cursor`, …
